# claude

Мої моди, плагіни й скіли для Claude Code. Репозиторій є маркетплейсом (каталогом плагінів) `renjeka`: кожен плагін лежить в окремій папці `plugins/<назва>`.

## Плагіни

| Плагін | Що робить |
|---|---|
| [session-dash](plugins/session-dash) | Панель «Сесія» поруч із чатом: скіли, MCP, агенти, плагіни й хуки, використання контексту і таймлайн подій поточної сесії. Вкладки, підказки при наведенні. Команда `/dash` відкриває панель. |
| [code-modules-refactor](plugins/code-modules-refactor) | Скіл рефакторингу за Остерхаутом («A Philosophy of Software Design», розд. 6 і 21): знаходить функції й модулі, підігнані під одного викликача, прапорці-перемикачі, функції-близнюки, змішування механізму з політикою. Складає план у `docs/refactor-audit/` і після «так» виконує порціями з тестами. TypeScript і Python/Frappe. |

## Як називаємо скіли

Шаблон: `<сфера>-<об'єкт>-<дія>`, латиницею, kebab-case, без скорочень.

- **Сфера** — технологія або проєкт, до якого належить скіл: `code` (код загалом), `frappe`, `youtrack`. Назви відділів і організацій у назву не вставляємо.
- **Об'єкт** — про що скіл, одним-двома словами: `naming`, `modules`, `form-layout`, `session`.
- **Дія** — завжди в кінці, з цього словника:

| Дія | Коли |
|---|---|
| `audit` | перевірити й скласти план, нічого не змінюючи до «так» |
| `refactor` | змінити код без зміни поведінки |
| `report` | скласти звіт про зроблене |
| `setup` | налаштувати або зробити щось у системі |
| `create` | створити новий файл чи артефакт |
| `add` | дописати запис у наявний документ |
| `import` | обробити вхідні матеріали |
| `start` / `close` | почати / завершити робочу сесію |
| `backup` | резервні копії й відновлення |

Нова дія додається в словник, лише коли жодна з наявних не підходить.

Приклади: `code-naming-audit`, `code-modules-refactor`, `frappe-form-layout-setup`, `frappe-change-report`, `youtrack-session-start`.

## Встановлення

У терміналі, в сесії Claude Code:

```
/plugin install session-dash --marketplace RenJeka/claude
```

Далі `y`, щоб додати маркетплейс, і Enter для області user (усі ваші сесії).

Зі звичайного терміналу (shell):

```
claude plugin install session-dash --marketplace RenJeka/claude
```

У десктоп-застосунку Claude, де `/plugin` не працює: натисніть + біля поля вводу → Plugins → Add marketplace, введіть `RenJeka/claude`, потім Add plugin.

## Оновлення

```
claude plugin marketplace update renjeka
claude plugin update session-dash@renjeka
```

Після цього в уже відкритій сесії виконайте `/reload-plugins`.
